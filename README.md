# Linux C 多人聊天室

基于 epoll LT + 线程池实现的多并发聊天服务器，支持昵称、群聊广播、系统通知与优雅关闭。

## 功能

- 多客户端同时在线聊天，消息广播给除发送者外的所有用户
- 连接后设置昵称，加入/离开有系统通知
- 客户端异常断开（如 kill -9）自动被巡检测并清理
- Ctrl+C 优雅关闭：排空任务队列、回收全部工作线程后退出

## 架构

- **主线程**：epoll LT 事件循环，负责 accept、收包（半包/粘包处理）、入队
- **线程池**：4 个工作线程从任务队列取任务，负责消息广播
- **协议**：自定义二进制帧（魔数 + 类型 + 长度 + 正文 + 校验和 + 帧尾），带错误检测

## 编译与运行

```bash
make            # 生成 bin/server 和 bin/client
make test       # 生成 bin/test（半包单元测试）
```

```bash
./bin/server                    # 启动服务器，默认监听 8888
./bin/client 127.0.0.1 8888     # 启动客户端（可开多个终端）
```

客户端输入昵称后即可聊天，输入 `quit` 退出。

## 测试

```bash
./bin/test                      # 半包单元测试（不依赖服务器）
./test_concurrent.sh            # 100 客户端并发压测
```

压测实测：100 并发，1000 条消息零丢失，断开全部正常清理。
